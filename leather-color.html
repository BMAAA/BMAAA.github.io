Калькулятор окрашивания брони

Вбиваешь цвет — получаешь красители. Считает по формуле Java Edition, не на глаз.

  • Все красители нужно положить в сетку крафта одновременно.
  • ΔE показывает, насколько цвет в игре схож с искомым. Чем меньше — тем ближе.
  • Считает пару секунд. Не ты один ждёшь.
